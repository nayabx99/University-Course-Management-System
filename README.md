\# University Course Management System



\## Assignment 1 — SQL Queries



\*\*Database:\*\* PostgreSQL  

\*\*Tool:\*\* pgAdmin 4



\## Project Overview

This project contains SQL queries for a University Course Management System, covering questions Q1–Q16.



\## Topics Covered

\- CRUD Operations

\- SELECT and WHERE clauses

\- Aggregate Functions

\- JOIN Operations

\- Grouping and Counting



\## How to Run

1\. Open pgAdmin 4.

2\. Connect to the database containing the required tables and data.

3\. Open `University\_Course\_Management\_System.sql`.

4\. Run the queries as required by the assignment.



\## Note

The queries depend on the database tables and sample data being available. The Salary query assumes that the Instructors table contains a Salary column.
